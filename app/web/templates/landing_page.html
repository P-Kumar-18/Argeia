    Argeia helps you turn intent into reliable action.

    Argeia is a lightweight behavior-aware planning system for personal execution. It combines scheduling, task progress, and simple state modeling so you can see not only what you planned, but how you actually behaved over time.

    What Argeia is

    At its core, Argeia is a task and behavior engine. It stores tasks, tracks start and completion events, evaluates behavioral signals, and keeps a current state you can monitor from the dashboard.

    How it works

    1. Plan: Schedule tasks with start and end windows.
    2. Execute: Start and end tasks as you work through them.
    3. Evaluate: Argeia analyzes timing and transitions between actions.
    4. Adapt: Use state and transition insights to improve your next plan.

    What it does for you

    • Shows your current behavioral state at a glance.
    • Separates upcoming work from completed execution.
    • Records transition history for reflection and analysis.
    • Creates a feedback loop between planning and real outcomes.

    Start by adding tasks, then open the dashboard to run your day with real-time feedback.
